# 🌦️ Weatherly

### A Modern Weather Analytics Web Application

Weatherly is a modern and user-friendly weather analytics web application designed to provide clear and accessible weather information for different locations.

The application connects with a weather API to retrieve dynamic weather data and presents it through a clean, responsive interface.

---

## ✨ Features

🌍 **Location Search**  
Search for weather information based on a specific location.

🌡️ **Weather Information**  
View important weather details such as temperature and weather conditions.

☁️ **Weather Conditions**  
Get a clear overview of the current weather.

📊 **Weather Analytics**  
Weather information is presented in an organized and easy-to-understand format.

📱 **Responsive Interface**  
Designed to provide a smooth experience across different screen sizes.

🎨 **Clean & Simple UI**  
A minimal interface focused on making weather information easy to understand.

## 🚀 Getting Started

Follow the steps below to run Weatherly locally.

### 1. Clone the Repository

git clone https://github.com/Sadani03/Weatherly.git

### 2. Navigate to the Project

cd Weatherly

### 3. Install Dependencies

npm install

### 4. Configure Environment Variables

Create a `.env.local` file in the root directory and add your weather API key.

NEXT_PUBLIC_WEATHER_API_KEY=your_api_key_here

🔐 **Important:** Keep your API key private and never commit `.env.local` to GitHub.

### 5. Run the Development Server

npm run dev

Then open the application in your browser:

http://localhost:3000
